## 1. 目标（一句话）
交付业务中立的文件管理能力：`StorageDriver` 抽象 + 本地磁盘通用实现（云驱动留扩展点）、`sys_file` 元信息表与上传/下载/列表/删除接口，上传安全四件套齐备，下载走鉴权接口不裸暴露静态目录。

---

## 2. 范围

### ✅ 包含
1. **`server/drivers/storage/`** — 存储驱动抽象 + 本地实现：
   ```go
   type StorageDriver interface {
       Put(ctx context.Context, key string, r io.Reader, size int64, contentType string) error
       Get(ctx context.Context, key string) (io.ReadCloser, error)
       Delete(ctx context.Context, key string) error
       Exists(ctx context.Context, key string) (bool, error)
       URL(ctx context.Context, key string) (string, error) // 返回可访问地址/相对引用；本地实现返回内部下载接口引用，非裸文件系统路径
   }
   ```
   - `LocalDriver`：存储根目录配置注入；key 即相对根目录的路径；**禁止越出根目录**（路径穿越防护，见 §5）。
   - 云驱动（OSS/S3/COS 等）**不在本片**——`StorageDriver` 为扩展点，消费方实现注入。底座不引入任何云厂商 SDK。
2. **`server/system/file_service.go`** — 文件元信息与编排：上传（生成 key、写驱动、落元信息）、下载（取元信息→驱动 Get→流式返回）、列表（分页/过滤）、删除（软删元信息 + 物理异步清理）。
3. **`sys_file`** 模型 + DDL（{{TABLE_PREFIX}} 占位、禁 AutoMigrate、前缀随实例）。
4. **handler**：上传 / 下载 / 列表 / 删除；全部挂 RequirePerm；下载为**鉴权接口**（流式返回，不暴露静态目录直链）。
5. **上传安全四件套**（全部本片必做，配置注入）：大小上限、扩展名白名单（或黑名单，二选一明确）、文件名消毒（防 `../` 路径穿越/控制字符/超长）、Content-Type 校验（与扩展名一致性，至少 MIME 嗅探或声明校验）。
6. **key 策略**：内部 key = `{yyyy}/{MM}/{dd}/{uuid}.{ext}`（日期分目录 + uuid 防冲突/防覆盖/防枚举）；原始文件名仅存 `sys_file.original_name` 供展示与下载命名。
7. spec：openapi 升 v0.7.0（文件路径 + multipart 上传 schema + 下载说明）；错误码注册进 response.Registry。
8. 单测（驱动 LocalDriver Put/Get/Delete/Exists/URL + 路径穿越防护 + 上传安全各分支 + 文件名消毒 + service 编排，docker-free，用临时目录 + SQLite）+ 集成测试 `//go:build integration`（真 MySQL 元信息 + 真磁盘本地驱动 端到端上传下载）。

### ⛔ 不包含
- 云存储驱动（OSS/S3 等）具体实现 → 扩展点，消费方实现。
- 图片处理/缩略图/转码 → 业务侧或后续，不在底座本片。
- 断点续传/分片上传 → 后续扩展，本片单次上传。
- 渲染收敛 → T-004c（独立）。配置中心 → T-005。前端 → admin 切片。

## 4. 接口契约

### 4.1 HTTP 接口（admin 端，挂 RequirePerm；对外 ID 走 hashid）
| 方法 | 路径 | perm code | 说明 |
|---|---|---|---|
| POST | /sys/files | sys:file:upload | multipart 上传，返回 file 元信息（含 hashid、下载引用） |
| GET | /sys/files/{id}/download | sys:file:download | 鉴权流式下载（Content-Disposition 用 original_name） |
| GET | /sys/files | sys:file:list | 分页列表（按上传人/时间/mime 过滤） |
| DELETE | /sys/files/{id} | sys:file:delete | 软删元信息 + 标记待物理清理 |

- 下载：**必须经此鉴权接口**；本地驱动的存储根目录**不**作为静态资源直接对外暴露。
- 上传响应不回传真实文件系统路径，只回 hashid + 下载接口引用 + 元信息。

### 4.2 StorageDriver / LocalDriver
- LocalDriver 构造注入根目录、URL 前缀（指向下载接口而非文件系统）；`Put` 自动按 key 建子目录；`Get` 返回流。
- `URL(key)` 返回的是**下载接口引用**（如 `/sys/files/{hashid}/download` 形态或相对引用），不返回 `/var/data/...` 这类真实路径。

### 4.3 上传安全（配置注入）
```yaml
file:
  max_size_bytes: 10485760      # 10MB，配置
  allowed_exts: ["jpg","jpeg","png","gif","pdf","docx","xlsx","zip"]  # 白名单，配置
  local:
    root_dir: ""                # 配置注入，禁硬编码
    url_prefix: ""              # 指向下载接口
```
- 文件名消毒：去除路径分隔符与 `..`、控制字符、限制长度；扩展名取自消毒后并对白名单校验。
- Content-Type：校验声明的 MIME 与扩展名一致（或对头部字节做 MIME 嗅探）；不一致拒绝。
- 大小：超 max_size_bytes 拒绝（流式读时即时判断，避免先全读进内存）。

### 4.4 错误码增量（注册进 response.Registry）
ERR_FILE_TOO_LARGE(413) / ERR_FILE_EXT_NOT_ALLOWED(415) / ERR_FILE_TYPE_MISMATCH(415) / ERR_FILE_NOT_FOUND(404) / ERR_FILE_NAME_INVALID(400) / ERR_STORAGE_FAILED(500)。

## 5. 安全要求
1. **路径穿越防护（头号）**：key 与文件名消毒后，LocalDriver 解析的最终绝对路径必须仍在根目录内（`filepath.Clean` + 前缀校验 / 拒绝 `..`）；任何越界一律拒绝。需有专门的穿越攻击测试用例（`../../etc/passwd` 等）。
2. **不裸暴露存储目录**：下载只走鉴权接口；根目录不挂静态路由；URL() 不泄漏真实文件系统路径。
3. **上传安全四件套**齐备且有测试：大小、扩展名、文件名消毒、Content-Type。
4. **下载鉴权**：下载接口挂 RequirePerm；流式返回，避免大文件全载内存。
5. **元信息不泄漏内部路径**：响应、日志均不含真实 storage 根路径；操作日志按 T-004a 脱敏。
6. **删除安全**：软删元信息；物理清理异步、失败仅告警不阻塞；清理逻辑只在根目录内操作（复用穿越防护）。
7. **业务中立 + DI**：StorageDriver 为接口，业务/云驱动注入；service/driver 不 import config（根目录、白名单、大小经构造/参数注入）；前缀随实例；grep 无硬编码专属值。
8. **错误码**：注册进 response.Registry，与既有段不冲突（沿用 T-004a 冲突 fail-fast）。
