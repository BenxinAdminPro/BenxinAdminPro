## 1. 目标
清理三项内聚的低优后端债——补全 file 错误文案、菜单父节点改用专属错误码、修 SetStatus 同值误返 404——零行为外扩、纯质量收尾。

## 2. 范围
✅ 包含（三项）：
1. file 文案补 6 键：response 渲染层补全 6 个 file 错误的 message 文案，消除返裸 i18n key。
2. 菜单父节点专属错误码：新增 ErrInvalidParentMenu（菜单专属·治本），menu_service.go 三处由复用 ErrInvalidParentDept 改用新码；文案"无效的父菜单"。errcode 段尾纯追加、不改既有码值。
3. SetStatus 同值 404 修复：status 设为相同值（RowsAffected==0）时区分"记录不存在"vs"无变更"——记录存在但值未变应返成功（幂等无变更），不返 404。修法：先确认记录存在，存在即视为成功。

⛔ 不包含：§8-4 dict_type 改名；§8-5 悬空 sys:secret:view；storage_key mask / openapi 强类型化 / junction 1062 / GORM logger 级别 / 日志清理粒度 / 超管短路 / 菜单父子类型校验 / 部门管理页 / PolicySync 原子性 / 集成测试硬编码端口 / T-003d-fix。无 DDL、无权限码、无新端点。
